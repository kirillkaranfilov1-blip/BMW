# Поймай квадрат

## Описание проекта

**«Поймай квадрат»** — простая браузерная игра на скорость и реакцию.

Задача игрока — нажимать на появляющийся квадрат как можно больше раз за ограниченное время.

## Возможности

* Система подсчёта очков.
* Таймер на 5 секунд.
* Случайное перемещение квадрата.
* Сохранение рекорда.
* Кнопка запуска игры.
* Адаптивный дизайн для мобильных устройств.
* Неоновый современный интерфейс.

## Технологии

* HTML5
* CSS3
* JavaScript

## Как играть

1. Нажми кнопку **«Начать игру»**.
2. На игровом поле появится квадрат.
3. Нажимай на квадрат как можно быстрее.
4. За каждый клик начисляется **1 очко**.
5. После окончания 5 секунд игра завершится.
6. Лучший результат сохраняется в поле **Record**.

## Цель

Набрать как можно больше очков за 5 секунд и установить новый рекорд.

## Автор

Проект создан в учебных целях для изучения HTML, CSS и JavaScript.
